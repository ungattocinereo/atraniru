# «Вкус гор»: новая фотография и кликабельные карточки

## Цель

Заменить текущее изображение гастрономической экскурсии «Вкус гор» фотографией `IMG_7372.jpeg` и сделать активные карточки раздела `/experience#experiences` кликабельными по всей площади.

## Изображение

- Исходник: `/Users/greg/Desktop/IMG_7372.jpeg`, квадрат 2988 × 2988.
- В репозиторий добавляется оптимизированная WebP-копия с понятным постоянным именем в `public/images/`.
- Новое изображение заменяет `/images/cooking-class.webp` только для экскурсии «Вкус гор»:
  - в карточке на `/experience#experiences`;
  - в hero страницы `/tours-gastronomy`;
  - в Open Graph и JSON-LD этой страницы через существующий параметр `image`;
  - в JSON-LD списка впечатлений на `/experience`.
- Изображение кадрируется через существующий `object-fit: cover`; фокус остаётся по центру, где находятся бокал и рука.
- Карточка будущих кулинарных мастер-классов продолжает использовать существующее `cooking-class.webp`.

## Кликабельные карточки

- Каждая доступная карточка становится одной семантической ссылкой на свою текущую посадочную страницу.
- Вложенная кнопка превращается в визуальный элемент без второй ссылки, чтобы не создавать недопустимые вложенные `<a>`.
- Сохраняются существующие тексты, цены, изображения, hover-анимация и внешний вид кнопки.
- Для клавиатуры вся карточка получает стандартный фокус и заметный `focus-visible` контур.
- Карточка «Кулинарные мастер-классы — открытие в 2026» остаётся некликабельным `<article>`.
- JavaScript для переходов не используется: ссылки остаются видимыми поисковикам и работают без клиентского кода.

## Проверки

- Автоматический тест сначала подтверждает отсутствие новой фотографии и ссылок на всю карточку, затем проходит после реализации.
- Проверяется, что все пять активных карточек ведут на прежние адреса, а карточка «Скоро» не становится ссылкой.
- Проверяется использование нового изображения в карточке, hero и schema-разметке.
- Запускаются все существующие тесты и production-сборка.
- После публикации проверяются `/experience`, `/tours-gastronomy`, загрузка нового изображения и навигация по карточкам.
